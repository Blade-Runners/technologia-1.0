# technologia-1.0
# 📦 Project Installation Guide

This repository contains the necessary files and scripts to install and set up the project on a Linux system.

## 🛠 Prerequisites

Before installing, make sure you have the following installed on your system:

- Git
- `chmod` permissions to run shell scripts

## 📥 1. Clone the Repository

First, clone the repository to your local machine:

```bash
git clone https://github.com/Blade-Runners/technologia-1.0.git
cd technologia-1.0/linux
./installer.sh
```
